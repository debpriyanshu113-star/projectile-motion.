Projectile model

Without air resistance: x = v₀ cos(θ)t and y = h₀ + v₀ sin(θ)t − ½gt².

With air resistance, the simulation uses small stable integration steps with quadratic drag opposing velocity: Fᵈ = ½ρCᵈA|v|v. The displayed predictions are calculated from those sampled positions.

Values use SI units. The maximum height is measured from ground level.
